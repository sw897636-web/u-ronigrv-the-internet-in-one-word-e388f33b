Entry for the [make.fun](https://make.fun) bounty
["The Internet in One Word"](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b):
describe the whole internet in exactly one word. The funniest and most
fitting word wins.

## The word

> Incognito

(9 characters.)

The whole internet, in one word: Incognito. Everyone online is browsing
like nobody can see them — new tab, private window, username that isn't
their name — while leaving a trail a mile wide. The joke lands the moment
you read it, and then you nod, because it's true.

## Why it fits the judge's five criteria

1. **One single word** describing the whole internet — not a phrase, a
   sentence, or a list.
2. **Funny by itself** — the private-browsing joke needs no explanation.
3. **True of the whole internet** — not one app, one site, or one mood:
   anonymity theatre is everywhere online.
4. **Surprising** — not the first obvious word anyone reaches for.
5. **Lands in one beat** — spelled correctly, instantly readable, nine
   characters.

## Run

```sh
node main.ts   # writes the word to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

`main.ts` runs on Node 22.18+ (TypeScript runs natively) and writes the single
word, with no trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
It is deterministic: every run writes the same bytes, with no network access.
